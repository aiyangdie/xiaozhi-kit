# Changelog

## [0.1.0] — 2026-03-26

### Added

- Monorepo: `xzkit_core`, `xzkit_cli`, `xzkit_server`
- CLI: `list`, `doctor`, `status`, `read`, `wait`, `send`, `reset`, `provision`, `preset`, `parse`, `service`, `serve`
- Log parser with SoftAP / MQTT / OTA / dialog / crash vs USB reset noise
- Provision assist (`status` / `open`)
- Pluggable services: health, provision, mqtt_probe, ota_probe
- Local Web console (Vite + React) via `xzkit serve`
- Cursor Skill + VitePress docs + GitHub Actions CI
